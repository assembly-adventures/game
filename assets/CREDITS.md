# Asset credits

Every third-party file in the game, where it came from, and its license. Add a row
here whenever you add an asset, and prefer CC0 or CC-BY: the repository is shared,
and many paid packs forbid publishing their raw files.

## Made for this project

- `audio/music/circuit_loop.ogg`: an original loop generated by `tools/make_music.py`.
  Edit and rerun the script to change it.
- `sprites/robot/*.svg` and `sprites/chomper/*.svg`: original vector art for the robot and
  the Chip Chomper (a corrupted FATAL_ERR pop-up window), drawn larger than their on-screen size. Edit them in any SVG editor
  (e.g., Inkscape) and keep each character's frames the same canvas size so animations
  don't jump.
